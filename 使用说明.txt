拾刻 1.0 — 透明桌面时钟

双击 Shike.exe 即可运行，无需安装或管理员权限。
适用：Windows 10 / 11，64 位。

主界面只有两行，左边缘对齐，视觉宽度一致：
12:34:56
10月19日 周1

第一行为本机时间，24 小时制，最后两位为秒；时间使用 Bahnschrift 半粗体，日期使用 Noto Sans SC Medium 设计字形。
第二行为本机日期；周1至周7对应星期一至星期日。
在时间字体缩小后，整体曾等比缩小 50%；按后续要求放大 25%，时间、日期和间距一起调整。
标准字号下窗口约为 105×45 像素（100% 屏幕缩放）。

操作
• 按住时钟区域的任意位置拖动，松开后自动记住位置。
• 可自由拖到任务栏区域，也可拖回桌面任意位置；保持“始终置顶”开启，松开鼠标后时钟会重新排到任务栏上方。
• 右键打开菜单：自动配色、浅字、深字、自选颜色、字号、置顶、找回位置、退出。
• 开机自动启动默认开启；右键菜单可随时关闭或重新开启。
• 默认自动配色：读取时钟背后画面的明暗，在浅色字与深色字间切换，约每秒检查一次。
• 自选颜色支持 Windows 原生调色板，可选任意颜色。
• 字号提供 75%、100%、125%、150%、200%，并适配屏幕 DPI。
• 托盘图标也能右键打开菜单；双击托盘图标或再次运行程序，可找回到主屏右上角。
• 退出：时钟或托盘图标上右键 → 退出拾刻。

设置保存在：%LOCALAPPDATA%\ShikeClock\settings.ini
关闭程序后删除该设置文件，可恢复默认值。
程序不联网；开机启动仅针对当前 Windows 用户，可在右键菜单关闭。

自动配色按整个时钟区域的整体明暗判断；复杂壁纸上可用右键固定配色。
背景使用逐像素透明；为让空白区域也可拖动，输入区域有 1/255 的透明度。
亮暗文字带少量柔和阴影，以便在照片壁纸上辨认。

附带 source 文件夹为完整 Rust 源码，无第三方 Rust 依赖。
重建需要 Rust stable（MSVC）、Visual Studio C++ Build Tools 和 Windows SDK。
进入 source 目录运行：powershell -ExecutionPolicy Bypass -File .\build.ps1
运行测试：cargo test --locked
